# POSTCARD.md

## 1. 明信片的产品角色

明信片不是到站通知、任务报告或内容推送皮肤。它是“本地的我”与“远方的我”之间最小、最重要的关系物件：一面保存贵州的此时此地，另一面说明这件事为什么要寄给这个用户。

地图让用户看见她走到哪里，明信片让用户明白自己为什么要在意。

## 2. 寄出的条件

明信片必须同时满足：

1. 有一个由真实外部状态支撑的具体时刻，或者一个经真实素材有边界改编的具体事件；
2. 有贵州地点、人物、文化或当下生活的可理解内容；
3. 有她自己的感受、选择或变化；
4. 能说清“为什么寄给你”，而不是泛化成任何用户都适用的话；
5. 物理输入和媒资性质可以展开查看；若使用故事、人物或文化解释，还需展示来源、事实与改编边界。

可触发寄出的时刻包括：天气与季节改变了她的穿搭、路线或心情；一个普通景象回应了远方线索；判断改变、兑现约定、关系发生变化、一次失败留下教训、离开与归来使旧事有了新理解。

以下情况不单独寄出：普通到站、机械报天气、只有景点资料、只有漂亮修辞、尚未核验的传闻、为了维持日活而拼出的日常。

## 3. 一张明信片的正反面

### 正面：她所在的贵州此刻

- 主图或影像，明确标识实拍、公开素材、授权素材或情境重构；
- 地点与路线位置；
- 日期和当地时间；
- 可核验的天气、温度、湿度与风；
- 一句不超过两行的现场标题。

### 反面：这件事怎样来到我们之间

- **先向你开口**：用符合寄信时段的一句问候，或“展信佳”“见字如面”这样的来信开场，让读者先知道这封信是在写给自己；
- **我在这里遇见了什么**：具体事件，不写景点百科；
- **身体记住了什么**：一个足够具体的感官细节；
- **这里真正发生过的故事**：如果本次确实涉及人物、文化或地方故事，再放入经检索核验的内容；没有故事时不强行补齐；
- **为什么这一刻会想到你**：只在真正相关时，让远方线索、共同记忆或约定自然进入正文；
- **我还没有想明白的事**：留一个真问题，不设计标准答案；
- **来源与改编**：折叠展示出处、版本、改编类型和不确定部分。

## 4. 用户可以怎样接住它

- **回一张给她**：写自己的此刻、记忆或不同看法；
- **夹进我们的手帐**：把它确认为共同长期记忆；
- **沿着这个故事继续**：请她以后多留意某个人、地方或文化线索，但不保证立刻改道；
- **告诉她我想起了什么**：把一段用户授权的个人线索加入双方关系；
- **先放在这里**：不回复，也不产生催促和惩罚。

“点赞”可以存在，但不能替代回信、收藏与追问这些真正建立关系的动作。

## 5. 明信片怎样改变后续旅行

用户回复进入共同记忆后，可以影响：

- 她以后对某类天气、食物、生活方式或文化关系的注意权重；
- 下一次研究时优先追问的角度；
- 是否重访一处没想明白的地方；
- 寄信语气与内容深度；
- 双方已经形成的约定和共同语言。

回复不能直接覆盖她的个人偏好，也不能绕过预算、安全、真实支付和对外发布确认。她可以自然回应：“我记住了，但我还想在这里多留一天。”

## 6. 寄送节奏

- 不按站点发送，按关系意义发送；
- 宁可一段旅程只有两三张真正需要寄出的信，也不制造每日流水账；
- 用户长期未读时自动降低频率，保留内容到“归来的一叠信”中；
- 不用倒计时、红点堆积和“她在等你”制造负担；
- 长旅程结束时，把明信片、回信、地图路径与改变汇成一章“我们多出的一页人生”。

## 8. 写作验收

- 开头是否像朋友真的写来一封信，而不是突然开始一段只对自己说的独白？
- 信中是否至少有一句明确面向收信人的话，让用户感觉自己在被写信，而不是旁观阿镜的日记？
- 如果删掉地点名，这仍是一件具体发生过的事吗？
- 如果换成任何用户，“为什么寄给你”还完全成立吗？若成立，说明个性连接太弱；
- 她在这张信里做了什么选择，或发生了什么变化？
- 用户能看见贵州，而不只看见她的情绪吗？
- 用户回复后，未来有什么可能真实改变？
- 物理输入是否足以支撑她声称看见、听见、闻到和感到的细节？
- 如果使用了人物或地方故事，来源与改编是否足以支撑，不会让虚构冒充见闻？
