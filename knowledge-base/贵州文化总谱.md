# 贵州文化总谱 V0.1

**建立日期**：2026-08-28
**用途**：为云游四方的文化知识库、无限画布、现场“听”和“看”提供第一版全域内容索引。
**当前规模**：13 个文化域，212 个种子条目。

这不是一份写完即封存的贵州文化百科。它先把贵州文化的主要门类、代表对象和关系搭起来，避免产品从少数景点或几项非遗出发，最后误把局部当成全部。

条目状态：

- **A**：已有 UNESCO、国家或省级政府、国家级名录等权威来源支撑，可进入事实整理。
- **B**：已有可靠公开资料作为种子，仍需补地方志、馆藏、学术研究或传承人口述。
- **C**：为了保证覆盖面暂列主题，正式进入产品前必须完成专项核验。

## 一、总览

贵州当前有 18 个世居民族。贵州现有人类非遗相关名录项目 3 项、国家级非遗代表性项目 99 项 159 处；贵州省政府公布第六批省级名录后，省级项目达到 727 项 1324 处。贵州还有 757 个村寨进入前六批中国传统村落名录，红军长征足迹遍及省内 60 多个县（市、区）。这些数字说明文化总量很大，也提醒我们：产品不能靠几张“代表性名片”代替完整梳理。[S02][S03][S05][S06][S24]

本总谱采用“双层结构”：后台按文化域维护，前台则把它们转成具体可见的入口，例如一只酸汤坛、一把银锤、一座鼓楼、一份山林契约或一段渡河声。

## 三、跨域关系主线

单个条目只有被关系串起来，才可能在画布中自然融合。首批建议建立以下 12 条文化主线：

1. **山与人怎么彼此塑造**：喀斯特 → 洞穴生存 → 山地聚落 → 石木建筑 → 山地交通。
2. **一口酸从哪里来**：稻作 → 缺盐与保存需求 → 发酵 → 酸汤 → 鱼稻共生 → 当代酸汤产业。
3. **一件盛装的一生**：蓝靛/银料 → 蜡染/刺绣/锻制 → 婚礼和节庆 → 家族传承 → 当代设计。
4. **没有文字时怎样保存知识**：苗族古歌、侗族大歌、水书、刻道、家谱与口述。
5. **鼓楼为什么会唱歌**：木构营造 → 寨社公共空间 → 歌班组织 → 侗族大歌 → 当代传承。
6. **一条江如何连接森林和世界**：清水江林业 → 木排 → 契约文书 → 商路 → 村寨社会。
7. **赤水河的多重时间**：盐运 → 茅台酿造 → 四渡赤水 → 当代酒旅。
8. **中央与地方如何相遇**：夜郎 → 土司 → 海龙屯 → 屯堡与卫所 → 贵州建省。
9. **从一座洞到一种思想**：王阳明入黔 → 龙场悟道 → 书院讲学 → 阳明文化当代转化。
10. **长征在贵州的连续空间**：黎平 → 猴场 → 乌江 → 遵义 → 娄山关 → 苟坝 → 四渡赤水。
11. **矿石如何改变一座城**：朱砂/煤 → 矿业 → 工人社区 → 资源转型 → 工业遗产。
12. **传统怎样在今天继续长**：非遗工坊 → 村超/村BA/村T → 路边音乐会 → 数字化记录。

## 四、内容节点字段

每个正式文化节点至少包含：

| 字段 | 必填 | 说明 |
|---|---:|---|
| id / name / aliases | 是 | 唯一编号、规范名、别名与民族语言名称 |
| domain | 是 | 后台文化域，可多选 |
| communities | 是 | 实践、传承或关联人群，不能只写“当地人” |
| places | 是 | 地点及其关系，不把地点当作唯一归属 |
| time_range / timeline | 是 | 起止、关键变化与当代状态 |
| short_definition | 是 | 80 字内的事实性定义 |
| origin_and_development | 是 | 起源证据、发展过程、争议与未知 |
| practices / objects / sounds | 至少一项 | 可被看见、听见或操作的具体内容 |
| relations | 是 | 与其他节点的明确关系和解释 |
| listen_entry | 否 | 现场可听内容、触发条件和声音授权 |
| see_entry | 否 | 可识别对象、拍摄要求和情境生成边界 |
| canvas_entry | 是 | 在画布中出现为什么具体形态 |
| evidence_items | 是 | 来源、证据等级、引用摘要、机构和日期 |
| rights | 是 | 文字、图片、音频、影像和模型训练/生成权限 |
| review_status / version | 是 | 草稿、审核、通过、退役与版本号 |
