# 贵州名胜手账｜第一卷内容方案 V0.1

**整理日期**：2026-08-28
**首卷规模**：24 处名胜，覆盖贵州 9 个市州
**产品关系**：与“贵州文化手账”并列，不替代文化卷；名胜卷负责回答“贵州有哪些地方值得抵达”，文化卷继续回答“这些地方为什么长成今天这样”。

## 一、这版不做景点排行榜

贵州的景点清单很容易被写成“瀑布、古镇、苗寨、溶洞”的重复罗列。名胜卷改用八种观看方式来装订：看水势、读世遗、走史迹、进村寨、沿城市、等季候、探深处、到高处。

每处景点至少回答五件事：

1. 第一眼该看什么；
2. 它真正特别在哪里；
3. 它和附近哪一处能连成一程；
4. 到现场最容易忽略什么；
5. 哪些信息会随天气、季节或管理安排变化，必须临行前重查。

## 三、四条自然长出的路线

### 1. 贵阳—安顺：从城市石楼到地表、地下的水

甲秀楼 → 青岩古镇 → 安顺屯堡 → 龙宫 → 黄果树瀑布

这条线适合第一次认识贵州。它把城市地标、古镇、活态村落和两种喀斯特水景放在一起，节奏从人文逐渐转向自然。

### 2. 黔东南：顺着村寨、河流和稻田走

镇远古城 → 施秉云台山 → 西江千户苗寨 → 肇兴侗寨 → 加榜梯田

这条线不要赶。古城、世遗山地、苗寨、侗寨和梯田都需要步行与停留，适合让 AI 旅人把沿途声音、村寨清晨和农事变化陆续带回来。

### 3. 黔西南—六盘水：从谷底到高原

马岭河峡谷 → 万峰林 → 乌蒙大草原 → 妥乐古银杏

峡谷是向下切开的贵州，峰林是被田野托住的贵州，草原和银杏则把旅程交给天气与季节。妥乐只在叶色合适时成为主角。

### 4. 黔北—铜仁：历史、丹霞、森林与矿脉

遵义会议会址 → 海龙屯 → 赤水丹霞 → 梵净山 → 朱砂古镇

这条线跨度较长，更适合云旅行或拆成两段。它的价值在于让五种完全不同的“贵州名片”进入同一条时间线，而不是追求短时间全走完。

## 四、统一内容底座，不统一页面模板

名胜卷首先是文旅科普手账。每页都要让用户快速获得可靠的基本信息，因此固定保留：

- 名称与一句话定位；
- 地址或主要分布地；
- 一张主图，以及必要的局部、人物或历史资料图；
- 基本介绍；
- 2—4 个核心特点；
- 到现场时留意；
- 临行前重查：天气、开放、预约、花情、水情或保护规定；
- 来源与边界。

统一的是信息完整度，不是视觉顺序。每页再从历史故事、文化背景、相关人物、传说、鲜为人知的故事、地质生态成因、工艺过程、过去与今天的变化和容易被误解之处中选择 2—3 项，让最有辨识度的内容成为版面主角。

### 跨页职责：左边去这里，右边读这里

景点跨页不再默认采用“左边一张大图、右边一篇介绍”。两页各自承担稳定职责：

- **左页是旅游现场**：回答这是哪里、为什么值得去、此刻能看到什么、怎样逛。内容包含基本介绍、地址、核心特点、多张现场图、短视频，以及在景区有稳定公开信号时出现的直播入口；路线、时长、最佳观察位置与保护提醒也放在这一侧。
- **右页是文化深读**：回答它为什么成为今天这样。每处只选择一条主线讲透，再根据内容加入历史事件、人物、地方记忆、器物、考古证据、传说与史实边界或鲜为人知的故事。

直播不是固定组件。有稳定直播时显示“正在直播”；没有直播时替换为景区或文化机构公开视频、航拍、声音采集或现场短片，不为了保持模板而塞进一个空窗口。开放时间、票务、天气、水量、花情等易变信息仍由实时服务提供，不写死在静态正文里。

左右职责稳定，但两页内部不使用统一栅格。照片可以是三张被夹入书中的观察图，也可以是全景与细节、旧图与今天、路线上的连续镜头；攻略可以长成路线纸条、页边批注或观看顺序；文化页可以长成时间线、人物口述、证据链、工艺步骤或一个完整故事。统一的装帧负责让它们属于同一本书，内容本身负责决定这一页长什么样。

- 自然景观页可由跨页大图、观看位置和季节变化组织；
- 历史遗址页可由时间线、旧图、人物和关键事件组织；
- 村寨与活态文化页可由人物、动作、空间和当代生活组织；
- 洞穴、矿山和科学设施页可由剖面、过程、证据或尺度对照组织；
- 故事型页面可由悬念、线索与“传说 / 史实”边界组织。

字体、纸张、页码、章签、地址标记、来源系统和翻页交互保持统一。这样读者知道自己仍在同一本书里，但不会连续翻到二十四张结构完全相同的页面。

## 五、首卷资料边界

- 景区等级只用于确认管理与公共服务基础，不作为内容排序标准。
- “最佳时间”不写死日期。花期、叶色、水量、云海和候鸟均使用官方实时信息。
- 村寨不是民族风情布景。西江、肇兴、加榜与屯堡页都保留居民生活、拍摄授权和私人空间边界。
- 自然保护区不鼓励“深入核心区”。草海页明确停止划船旅游、关闭码头，以指定区域的远距离观鸟为主。
- 世界遗产、地质公园与文保单位的名称和价值，以 UNESCO、文化和旅游部及贵州省官方资料为准。
- 门票、营业时间、交通接驳和预约规则变化快，不写进静态正文；正式产品应单独接实时服务。
