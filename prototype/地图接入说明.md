# 云游四方地图接入说明

当前原型已经支持两种地图运行方式：

- 配置高德 Key：使用高德 JS API 2.0，开启真实地图、地址反查和当前位置周边地点发现。
- 未配置高德 Key：自动回退到现有 Leaflet + OpenStreetMap 地图，路线和旅程交互仍可正常演示。

## 接入高德

1. 在[高德开放平台控制台](https://console.amap.com/dev/index)创建应用。
2. 分别创建“Web 端（JS API）”Key 和“Web 服务”Key。前者负责渲染地图，后者负责路线、逆地理编码和周边搜索。
3. 打开 `prototype/map-config.js`，填入：

```js
window.CLOUD_WAYFARER_MAP_CONFIG = {
  provider: "auto",
  amapKey: "你的 Web 端（JS API）Key",
  amapSecurityJsCode: "控制台提供的安全密钥，没有则留空",
  amapWebServiceKey: "你的 Web 服务 Key",
  nearbyRadius: 3000
};
```

4. 通过本地 Web 服务打开 `prototype/index.html`。高德 Key 不能在直接双击打开的 `file://` 页面中稳定运行。

建议在高德控制台限制可调用域名、IP 和额度。当前静态原型会在浏览器中调用 Web 服务，适合内部验证；正式上线时应由服务端代理路线和地点请求，不把 Web 服务 Key 暴露在前端。

## 已接通的能力

- 高德 2D/3D 真实地图和缩放、拖动；
- 将 OSM/GeoNames 常用的 WGS84 坐标转换后叠加在高德底图上；
- 现有 Agent、五个旅程节点和道路路线继续共用同一份旅程状态；
- Agent 移动时，每移动约 1.2 公里或间隔 90 秒，更新一次附近感知；
- 高德根据起点、终点和途经点返回完整驾车道路折线，Agent 与已走路线严格使用同一份折线；
- 反查当前位置的地址；
- 搜索当前位置 3 公里内的景区、博物馆、古迹、村寨和公园；
- 地图展开后，在左下角展示附近地点，并支持点击查看地点摘要；
- 高德加载失败时自动回退到 OSM，不阻断原型。

## 数据边界

高德返回的地址、POI 和路线用于产品内的实时展示，不批量抓取或沉淀为云游四方自己的永久数据库。贵州长期数据库仍然使用 OSM、GeoNames、Wikidata、Wikipedia、GBIF、iNaturalist 等允许下载或再利用的数据源。高德算路不可用时，原型才会回退到项目内保存的 OSRM 道路快照，不会用两点直线代替。

这样形成两层：高德负责“Agent 此刻在哪里、附近有什么”，云游四方数据库负责“这个地方背后有什么文化和故事”。
